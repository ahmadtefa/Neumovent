# Neumovent GraphNet Advance — browser preview

This branch contains a **lightweight interactive browser preview** at [web/index.html](web/index.html). It includes a rotary knob controlled with the mouse wheel or drag, a click-to-confirm interaction, mode menu, parameter tiles and three illustrative waveforms.

**Important:** This is a simplified preview uploaded directly to GitHub, **not the full local v0.3 Flutter ZIP**. The original Flash file, the reference video and the fuller Flutter source have not been uploaded to this branch. The waveforms and mode behavior are educational placeholders, not a clinically validated simulation.

To run: download `web/index.html` from GitHub (Raw → Save As), then open it in Chrome or Edge. No server is needed.

Original repository main branch is unchanged.
